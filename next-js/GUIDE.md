# Guia local - Next.js

Este guia cobre somente implementacao local do front-end em Next.js.

## Fluxo local

1. Receber task da raiz (`../tasks/*.md`)
2. Confirmar que `Tipo` inclui `front` ou `shared`
3. Confirmar que `Stacks envolvidos` indica `next-js`
4. Implementar apenas o escopo Next.js
5. Rodar validacoes locais
6. Reportar resultados para consolidacao da task na raiz

## Nao e responsabilidade local

- gerar backlog global
- definir ordem global de tarefas
- atualizar contrato sem task especifica
- inferir regras mobile a partir da UI web

## Comandos principais

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run lint`
- `npm run typecheck`
