# Regras de atualizacao da task (next-js)

Ao concluir o escopo local `next-js`, registrar na task da raiz:

- `## Resultado da execucao`: o que foi feito, decisoes tecnicas locais
- `## Arquivos alterados`: caminhos dentro de `next-js/`
- `## Validacoes executadas`: `lint`/`typecheck`/`build`, mais gates web com numero quando a task tocou rota publica
- `## Pendencias pos-task`: o que ficou para outra task ou depende de decisao humana

Nao editar `tasks/000-index.md` fora do que a task da raiz pedir. Nao criar handoff fora de `.agents/state/handoffs/` da raiz do projeto.
