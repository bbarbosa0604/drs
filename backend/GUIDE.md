# Guia local - Backend

Este guia cobre somente implementacao local do backend.

## Fluxo local

1. Receber task da raiz (`../tasks/*.md`)
2. Confirmar que `Tipo` inclui `back` ou `shared`
3. Implementar apenas o escopo backend
4. Rodar validacoes locais
5. Reportar resultados para consolidacao da task na raiz

## Nao e responsabilidade local

- gerar backlog global
- definir ordem global de tarefas
- executar fluxo de planejamento completo

## Comandos principais

- `npm install`
- `npm run start:dev`
- `npm run build`
- `npm run lint`
- `npm run test`
- `npm run test:e2e`
