# AGENTS

Projeto local de backend (NestJS + TypeScript).

Este arquivo define apenas governanca local de implementacao.
A orquestracao global do projeto fica na raiz em:
- `../AGENTS.md`
- `../GUIDE.md`

## Papel desta stack

- implementar tasks classificadas como `back`
- participar de tasks `shared` quando indicado em `Stacks envolvidos`
- manter aderencia ao contrato em `../contracts/openapi.yaml`

## Leitura obrigatoria antes de implementar

- `../AGENTS.md`
- `../GUIDE.md`
- `../requirements/`
- `../contracts/openapi.yaml`
- `docs/ai/AGENTS.md`

## Skills locais

Skills locais em `.agents/skills/` sao focadas em implementacao backend.
Planejamento global e change request devem ser feitos por skills da raiz.
