# Identidade visual Daryus — tokens de referência

Fonte primária: `design-system/front/brand/daryus-brandbook.pdf` (Brand Book oficial, RGB/Pantone).

## Cores (RGB/HEX oficiais do brandbook)

| Token sugerido       | HEX       | RGB           | Uso no brandbook                               |
| -------------------- | --------- | ------------- | ---------------------------------------------- |
| `brand-tint`         | `#FFAD85` | 255, 173, 133 | tinta/apoio claro                              |
| `brand-primary`      | `#FF6920` | 255, 105, 32  | cor principal (símbolo, CTA, destaque)         |
| `brand-primary-dark` | `#A33600` | 163, 54, 0    | hover/estado ativo da cor principal            |
| `brand-navy`         | `#1D2833` | 29, 40, 51    | cor secundária / texto da marca / fundo escuro |
| `brand-ink`          | `#070A0D` | 7, 10, 13     | quase-preto, texto de alto contraste           |

Regras de aplicação do brandbook (seção "Logo Misuses"):

- não trocar as cores da marca por outras (ex.: azul genérico) — usar exatamente os tons acima;
- manter contraste mínimo: laranja sobre navy/preto ou branco; navy sobre fundo claro;
- símbolo (triângulo) sempre nas variações A/B/C/D do brandbook (cor principal, navy, cinza escuro, cinza claro) — nunca gradientes ou cores fora da tabela.

## Tipografia

- **Título / uso comercial:** `Montserrat Bold` (Google Fonts).
- **Texto corrido / documentos corporativos:** `Lato` (Regular/Semibold/Bold, Google Fonts).

## Escopo desta referência

Este arquivo resume tokens de cor/tipografia extraídos do brandbook para uso em tasks `front` (`next-js`) do DSR. Uso de logo, papelaria e aplicações de marca (camiseta, caneca, escritório) seguem o PDF original e não são escopo de UI do produto.
